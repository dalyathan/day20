# Real-world set: messages scam sellers actually sent buyers

Each file is one message a buyer quoted word for word in a public thread, frozen here on 2026-11-11 before
Day 20 scored it (rules or Claude). The only thing we added is the same two-line header on every file
(`From: Seller support` / `Subject: About your PayPal dispute`), so it reads as an email to Maya.
Nothing in Day 20 was tuned on these. Typos and spacing are the scammers' own.
